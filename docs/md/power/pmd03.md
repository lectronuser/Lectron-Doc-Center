# Lectron PMD03

## **Dual Output BEC with Telemetry**

Dual output BEC with 5.2V and selectable 5V / 8V / 12V rails.

## **Specification**

| Feature | Lectron PMD03 |
| --- | --- |
| **Input Voltage** | 3S - 12S (14S Optional) |
| **Output Voltage** | 5.2V & 5V / 8V / 12V (Select With Solder) |
| **Continuous Current** | 2.5A @ 5.2V & 5A @ 8V |
| **Burst Current** | 3A & 8A |
| **TVS Protection** | Yes |
| **Telemetry** | Voltage & Current |
| **Telemetry Interface** | I2C |
| **Connector (IN)** | Solder PAD |
| **Connector (OUT)** | 2 × 6 Pin (JST GH & Molex) & Solder PAD |
| **Protocol Support (PWM)** | MultiShot/OneShot/Proshot/PWM |
| **Status Indicator** | 2 × Led |
| **Weight** | ~ 6 g |
| **Dimensions** | 28 × 46 × 12 mm |
| **Mounting Holes** | - |
