# Lectron PDB-300

## **300A Power Distribution Board**

High-current power distribution board with XT90 and XT30 outputs.

## **Specification**

| Feature | Lectron PDB-300 |
| --- | --- |
| **Input Voltage** | DC IN |
| **Output Voltage** | DC IN |
| **Continuous Current** | 300A |
| **Burst Current** | 500A |
| **TVS Protection** | - |
| **Telemetry** | - |
| **Telemetry Interface** | - |
| **Connector (IN)** | 2 × M6 Screw Terminal |
| **Connector (OUT)** | 6 × XT90 & 2 × XT30 |
| **Protocol Support (PWM)** | - |
| **Status Indicator** | - |
| **Weight** | ~ 100 g |
| **Dimensions** | 100 × 53 × 25 mm |
| **Mounting Holes** | 35 × 46 mm, 4 × 3 mm Dia Hole |
