# Lectron PMD02

## **BEC with Voltage & Current Telemetry**

5.2V BEC with voltage and current telemetry over I2C.

## **Specification**

| Feature | Lectron PMD02 |
| --- | --- |
| **Input Voltage** | 3S - 12S (14S Optional) |
| **Output Voltage** | 5.2V |
| **Continuous Current** | 2.5A @ 5.2V |
| **Burst Current** | 3A |
| **TVS Protection** | Yes |
| **Telemetry** | Voltage & Current |
| **Telemetry Interface** | I2C |
| **Connector (IN)** | Solder PAD |
| **Connector (OUT)** | 2 × 6 Pin (JST GH & Molex) |
| **Protocol Support (PWM)** | MultiShot/OneShot/Proshot/PWM |
| **Status Indicator** | Led |
| **Weight** | ~ 20 g |
| **Dimensions** | 26 × 32 × 12 mm |
| **Mounting Holes** | - |
