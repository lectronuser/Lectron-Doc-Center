# Lectron PMD01

## **Selectable Output BEC**

Compact BEC with solder-selectable 5V / 8V / 12V output.

## **Specification**

| Feature | Lectron PMD01 |
| --- | --- |
| **Input Voltage** | 3S - 12S (14S Optional) |
| **Output Voltage** | 5V / 8V / 12V (Select With Solder) |
| **Continuous Current** | 5A @ 8V |
| **Burst Current** | 8A |
| **TVS Protection** | Yes |
| **Telemetry** | - |
| **Telemetry Interface** | - |
| **Connector (IN)** | Solder PAD |
| **Connector (OUT)** | Solder PAD |
| **Protocol Support (PWM)** | MultiShot/OneShot/Proshot/PWM |
| **Status Indicator** | Led |
| **Weight** | ~ 9 g |
| **Dimensions** | 23 × 30 × 4.5 mm |
| **Mounting Holes** | - |
