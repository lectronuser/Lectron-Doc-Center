# Power Modules

Lectron power products cover BEC modules for regulated supply rails and a high-current power distribution board.

## **Products**

| Product | Description | Status |
| --- | --- | --- |
| [Lectron PMD01](pmd01.md) | Compact BEC with solder-selectable 5V / 8V / 12V output. | Available |
| [Lectron PMD02](pmd02.md) | 5.2V BEC with voltage and current telemetry over I2C. | Available |
| [Lectron PMD03](pmd03.md) | Dual output BEC with 5.2V and selectable 5V / 8V / 12V rails. | Available |
| [Lectron PDB-300](pdb-300.md) | High-current power distribution board with XT90 and XT30 outputs. | Available |
