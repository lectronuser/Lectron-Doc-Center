# Lectron H7 FPV

## **Compact FPV Flight Controller**

The Lectron H7 FPV is a compact, lightweight flight controller built around the STM32H743 processor, designed as an entry point into Lectron's FPV flight controller lineup.

It shares its core sensor set and software support with the H7 FPV Pro, while keeping a simplified connectivity set for standard FPV racing and freestyle builds.

## **Product Description**

Lectron H7 FPV supports PX4, ArduPilot, iNav, and Betaflight, giving pilots the flexibility to run the firmware of their choice on a single hardware platform.

With a 36 × 36 mm footprint and a lightweight aluminum case, it is designed to drop into standard FPV frames without adding unnecessary weight or complexity.
