# Electronic Speed Controllers

Lectron ESCs are built around STSPIN32 controllers with integrated gate drivers, and are available as single and 4-in-1 boards.

| Product | Description | Status |
| --- | --- | --- |
| [Lectron 12S 100A Single ESC](12s-100a-single.md) | Single ESC for 3S - 12S systems, 100A continuous. | In design |
| [Lectron 12S 100A 4in1 ESC](12s-100a-4in1.md) | 4-in-1 ESC for 3S - 12S systems, 4 × 100A continuous. | In design |
| [Lectron 8S 80A Single ESC](8s-80a-single.md) | Single ESC for 3S - 8S systems, 80A continuous. | In design |
| [Lectron 8S 80A 4in1 ESC](8s-80a-4in1.md) | 4-in-1 ESC for 3S - 8S systems, 4 × 80A continuous. | In design |
