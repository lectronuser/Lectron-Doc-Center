# Lectron 6S 60A Single ESC

## **6S 60A Single ESC**

!!! note "In design"
    This product is currently in the design phase. Specifications may change before release.

Single ESC for 3S - 6S systems, 60A continuous.

## **Specification**

| Feature | Lectron 6S 60A Single ESC |
| --- | --- |
| **Main Processor** | STSPIN32G0 |
| **Gate Driver** | STSPIN Integrated |
| **Firmware** | AM32 / BLHELI32 |
| **Power Input** | 3S - 6S |
| **Continuous Current** | 60A |
| **Burst Current** | 70A |
| **Measurements (ADC)** | Voltage & Current |
| **ESC Telemetry** | Yes |
| **PWM Frequency** | 8 kHz to 96 kHz |
| **Protocol Support (Dshot)** | 150/300/600/1200 |
| **Protocol Support (PWM)** | MultiShot/OneShot/Proshot/PWM |
| **Status Indicator** | RGB Led |
| **Weight** | ~ 6 g |
| **Dimensions** | 17 × 35 × 6 mm |
| **Mounting Holes** | - |
