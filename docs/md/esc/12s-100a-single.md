# Lectron 12S 100A Single ESC

## **12S 100A Single ESC**

!!! note "In design"
    This product is currently in the design phase. Specifications may change before release.

Single ESC for 3S - 12S systems, 100A continuous.

| Feature | Lectron 12S 100A Single ESC |
| --- | --- |
| **Main Processor** | STSPIN32G4 |
| **Gate Driver** | STSPIN Integrated |
| **Firmware** | AM32 |
| **Power IN** | 3S - 12S |
| **Continuous Current** | 100A |
| **Burst Current** | 120A |
| **Measurements (ADC)** | Voltage & Current |
| **ESC Telemetry** | Yes |
| **PWM Frequency** | 8 kHz to 48 kHz |
| **Protocol Support (Dshot)** | 150/300/600/1200 |
| **Protocol Support (PWM)** | MultiShot/OneShot/Proshot/PWM |
| **Status Indicator** | RGB Led |
| **Weight** | ~ 9 g |
| **Dimensions** | 24 × 55 × 6 mm |
| **Mounting Holes** | - |
