# Lectron H7 Matrix

## **High Channel Count Flight Controller**

The Lectron H7 Matrix is a standalone flight controller built around the STM32H743 processor, designed for platforms that require a large number of PWM outputs and flexible connectivity without an onboard mission computer.

Its compact form factor and rich set of ports make it suitable for multirotor and fixed-wing platforms that need extensive actuator control alongside reliable sensing and redundancy.

## **Product Description**

Lectron H7 Matrix focuses on maximizing PWM output count and CAN connectivity for complex actuator configurations, while retaining the sensor redundancy and software flexibility expected from a Pixhawk-class flight controller.

With support for PX4 and ArduPilot, it is well suited for research, industrial, and specialized aerial platforms that require more outputs than a typical flight controller provides.
