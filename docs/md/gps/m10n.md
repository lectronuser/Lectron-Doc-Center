# Lectron M10N GPS

## **CAN GNSS Module with Compass**

!!! note "In design"
    This product is currently in the design phase. Specifications may change before release.

u-blox M10N GNSS module with compass and CAN interface.

## **Specification**

| Feature | Lectron M10N GPS |
| --- | --- |
| **Main Processor** | Ublox M10N |
| **Protocol** | GPS, GLONASS, Galileo, BeiDou, QZSS, SBAS |
| **Frequency** | 1.561 GHz, 1.575 GHz, 1.602 GHz |
| **Data Rate** | 921.6 kbps |
| **Sensitivity** | -167 dBm |
| **Compass** | IST8310 |
| **Connector** | 4 Pin JST GH |
| **Interface** | CAN |
| **Power IN** | 5V |
| **Button Function** | Safety Switch In |
| **LED Functions** | Safety, GPS Fix, RGB(Status) |
| **RGB Led Driver** | IS31FL3195 |
| **Buzzer** | Yes |
| **Operating Temperature** | -40°C ~ 85°C |
| **Weight** | ~ 20 g |
| **Dimensions** | 35 × 35 × 14 mm |
