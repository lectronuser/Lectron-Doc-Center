# Lectron F10N GPS

## **Dual-Band GNSS Module with Compass**

Dual-band u-blox F10N GNSS module with compass, safety switch and buzzer.

## **Specification**

| Feature | Lectron F10N GPS |
| --- | --- |
| **Main Processor** | Ublox F10N |
| **Protocol** | BeiDou, Galileo, GNSS, GPS, QZSS |
| **Frequency** | 1.176 GHz, 1.575 GHz |
| **Data Rate** | 921.6 kbps |
| **Sensitivity** | -167 dBm |
| **Compass** | IST8310 |
| **Connector** | 10 Pin JST GH |
| **Interface** | UART & I2C |
| **Power IN** | 5V |
| **Button Function** | Safety Switch In |
| **LED Functions** | Safety, GPS Fix, RGB(Status) |
| **RGB Led Driver** | IS31FL3195 |
| **Buzzer** | Yes |
| **Operating Temperature** | -40°C ~ 85°C |
| **Weight** | ~ 27 g |
| **Dimensions** | 35 × 35 × 14 mm |
