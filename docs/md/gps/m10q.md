# Lectron M10Q GPS

## **Compact GNSS Module with Compass**

!!! note "In design"
    This product is currently in the design phase. Specifications may change before release.

Small and lightweight u-blox M10Q GNSS module with compass.

## **Specification**

| Feature | Lectron M10Q GPS |
| --- | --- |
| **Main Processor** | u-blox M10Q |
| **Protocol** | Galileo, GLONASS, GPS |
| **Frequency** | 1.575 GHz, 1.602 GHz |
| **Data Rate** | 400 kbps |
| **Sensitivity** | -165 dBm |
| **Compass** | IST8310 |
| **Connector** | 6 Pin JST GH |
| **Interface** | UART & I2C |
| **Power Input** | 5V |
| **Button Function** | - |
| **LED Functions** | GPS Fix |
| **RGB Led Driver** | - |
| **Buzzer** | Yes |
| **Operating Temperature** | -40°C ~ 85°C |
| **Weight** | ~ 10 g |
| **Dimensions** | 20 × 20 × 12 mm |
