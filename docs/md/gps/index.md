# GPS & Sensor Modules

Lectron GNSS modules combine a u-blox receiver with an onboard IST8310 compass, and are available with UART & I2C or CAN interfaces.

## **Products**

| Product | Description | Status |
| --- | --- | --- |
| [Lectron F10N GPS](f10n.md) | Dual-band u-blox F10N GNSS module with compass, safety switch and buzzer. | Available |
| [Lectron M10Q GPS](m10q.md) | Small and lightweight u-blox M10Q GNSS module with compass. | In design |
| [Lectron M10N GPS](m10n.md) | u-blox M10N GNSS module with compass and CAN interface. | In design |
| [Lectron M9N GPS CAN](m9n-can.md) | u-blox M9N GNSS module with compass and CAN interface. | In design |
| [Lectron M9N GPS](m9n.md) | u-blox M9N GNSS module with compass and UART & I2C interface. | In design |
